# Community Guidelines & Repository Information

Welcome to the official repository resources for Invoza ([https://getinvoza.com](https://getinvoza.com)).

---

## 1. Project Overview

Invoza is a free online invoice generator engineered to help freelancers, contractors, and small business owners generate clean, professional invoices directly in their browser without signing up.

---

## 2. Code of Conduct & Participation Standards

When interacting with official Invoza repository spaces, issue trackers, or documentation discussions, all participants are expected to uphold a respectful, constructive, and professional environment.

- **Professional Communication**: Focus discussions on constructive feedback, accurate bug reports, and factual improvements.
- **Respect & Inclusivity**: Treat all members with courtesy regardless of experience level, background, or identity.
- **No Spam or Self-Promotion**: Avoid posting advertisements, unsolicited marketing links, or irrelevant commercial promotions.

---

## 3. Contribution Status

*Notice regarding contributions:*

The Invoza repository is currently maintained as a focused software product. At this stage, formal public pull request workflows and external code contributions are not active unless specifically announced on the repository home.

### How You Can Help
- **Reporting Issues**: If you discover a bug or calculation discrepancy while using [getinvoza.com](https://getinvoza.com), please open a detailed issue providing reproduction steps, browser version, and observed versus expected behavior.
- **Feature Feedback**: Constructive suggestions for template designs, currency formats, or export adjustments can be submitted via the issue tracker or through the feedback avenues listed on [https://getinvoza.com/about](https://getinvoza.com/about).

---

## 4. Security & Vulnerability Reporting

If you identify a security or privacy concern, please disclose it responsibly. Do not open public issues for sensitive vulnerabilities; report them through the official contact channels on [https://getinvoza.com](https://getinvoza.com).
